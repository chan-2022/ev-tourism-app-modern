# 앱형 버전 시연 순서

1. 3002 홈에서 네이비·아이스 블루 앱 화면과 충전소 지도를 소개합니다.
2. 강릉 → ‘시연 예시’ 서부시장주차장 → 설치 충전기 수와 지역 유형 설명을 확인합니다.
3. ‘모의 체크인 시작’ → ‘모의 스캔 완료’. 카메라나 방문 인증이 없는 시뮬레이션임을 설명합니다.
4. 주변 장소 예시를 확인합니다. 카페 필터에는 준비된 예시가 없으며 ‘전체 예시 보기’로 돌아갑니다.
5. 모의 쿠폰을 펼쳐 사용 시뮬레이션을 누르고 의견을 남깁니다. 실제 할인이나 방문 성과가 아닙니다.
6. 처음부터 → 홍천에서 장소 정보가 없는 상황의 안내를 확인합니다.
7. 원주·속초·춘천에서도 같은 흐름을 체험합니다.

앱의 다섯 지역은 시연 사례이며 D·U로 최종 선정된 대표 사례가 아닙니다. 분류축은 A_dest·A_route입니다. D는 방문·소비 각 50%의 관광수요 지표입니다.

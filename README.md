# 강원 EV 관광 — 앱형 리디자인 데모

기존 앱의 충전소 선택 → 상세 → 모의 QR 체크인 → 주변 장소·혜택·피드백 흐름을 유지하고, 네이비·아이스 블루 디자인으로 개편한 별도 버전입니다. 긴 소개 페이지와 분석 산점도는 포함하지 않습니다.

## 실행
Node.js 24 권장. 프로젝트 폴더에서:

```sh
npm ci
npm start
```

http://127.0.0.1:3002 에서 실행됩니다. 기본 시연에 API 키나 .env 파일은 필요 없습니다. `npm test`로 API 테스트 6개를 실행합니다.

## 사용
강릉·원주·홍천·속초·춘천을 선택하고 ‘시연 예시’ 충전소를 누르세요. QR은 카메라 없이 버튼으로 체험합니다. 홍천은 준비된 장소 정보가 없는 상황을 보여줍니다. 일반 충전소는 고정 예시가 없을 수 있습니다.

충전기 수는 설치 수이며 실시간 상태가 아닙니다. 장소의 영업·보행 접근성은 별도 확인이 필요합니다. QR·쿠폰은 시뮬레이션이며 제휴·할인·방문을 인증하지 않습니다. 피드백은 별도 `server/data/app-modern-feedback.db`에 저장하고 세션·응답 유형별 중복을 막습니다.

지도 타일에는 인터넷이 필요합니다. 실패해도 목록과 시연은 사용할 수 있습니다. 폰트·Leaflet·장식 이미지는 로컬 제공됩니다. 새로고침 시 홈부터 시작합니다.

## 환경변수
`.env`는 저장소에 포함되지 않습니다(비밀 키 보호). 없어도 기본값으로 실행됩니다. 실시간 네이버 검색이 필요하면 `cp .env.example .env` 후 `ENABLE_EXTERNAL_SEARCH=true`와 `NAVER_APIGW_KEY_ID`, `NAVER_APIGW_KEY`를 채우세요. 값은 배포 환경의 환경변수로 직접 주입해도 됩니다.
